# Vibing Studio 开发日志

公开版说明见 [changelog.js](../ui/studio/changelog.js)。以下按实际交付版本记录实现与验证。

## 0.2.5.2 · 2026-11-29

- 修复连续打开命令面板或切换选择器时旧遮罩残留、工作台持续处于 inert 状态的问题。独立 Mac 窗口中，旧版关闭面板后残留一层空遮罩；修复后重复打开、切换并按 Esc，残留为零，点击成功切换到活动监视器。
- 本地保留最近 16 次浮层开关及当时的交互状态，便于重载后排查同类故障。

## 0.2.5.1 · 2026-11-29

- 文件链接的虚线绘制在文字框内，跨行分片独立绘制。用真实字幕 diff 回复核对 11 号字的 Retina 截图，修复后可见两行物理像素的虚线。

## 0.2.4.27 · 2026-11-28

- 对话流式追加文字使用 Text.appendData 保留 Range。结构变化涉及选中的节点时，延后替换，取消选择后用最新记录补画。选择期间暂停自动贴底，短会话保持当前位置，选区几何未变时复用高亮节点。

## 0.2.4.26 · 2026-11-28

- Mac 本地 MP4、M4V、MOV 使用 AVPlayerView 读文件，不启动 HTTP 子进程，支持系统浮动控件、精确跳转与关闭释放。页面复用工作台浮层遮挡逻辑，解码失败回退至页面播放器。
- Mac 实际打开同一段 4096 × 2304、1.32 GB MOV 各三次。旧播放器打开至首帧 910、718、648 ms，新播放器打开至可显示 361、49、48 ms。连续跨段跳转后旧版回到目标画面需 339–382 ms，新版完成定位并在目标处继续播放需 198–205 ms。两个播放内核的回调不同。最终签名安装包复测 MOV：首次 295 ms，再次 70、47 ms，连续跳转后 198–208 ms；另一个 73.6 MB MP4 首次 216 ms，连续跳转后 153 ms。

## 0.2.4.25 · 2026-11-28

- 在文本大小限制和二进制探测前识别视频，文件页使用系统内核的视频控件。本机通过绑定回环地址的单文件服务处理字节范围；远程文件桥分块读取到 Blob。关闭播放器时释放服务或对象 URL。
- 两次在 Mac 窗口打开实际 MP4 和 MOV，其中一次使用正式 HTTPS 界面地址。记录到解码帧、暂停、跳至中点和跳转后时间继续推进，MOV 为 4096 × 2304、1.32 GB。核对 Range 返回 206，关闭对应标签后连接已释放。未在远程浏览器实测。

## 0.2.4.24 · 2026-11-28
