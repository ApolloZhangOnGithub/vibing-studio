# Vibing Studio 开发日志

公开版说明见 [changelog.js](../ui/studio/changelog.js)。以下按实际交付版本记录实现与验证。

## 0.2.4.7 · 2026-11-28

- macOS 构建 316 在主文档提交时清理其原生网页视图。快速预览切换时关闭旧视图，网页端跨重载记录视图 ID。在独立 Studio 窗口打开本地 TensorBoard 并重载，旧构建仍能查询到原视图，修复后原视图已移除。
- 文件图片合并每帧缩放事件，将精确滚动与鼠标滚轮分流。实际打开 1008 × 1852 图片，放大后两轴均有 10 px 滚动条，可在维持倍率时移动视口。
- AGY 历史通过压缩 NDJSON 分批解码，工具按 ID 索引，IndexedDB 按页分组处理。TUI 按实际块高填充首屏并合并相邻同类字符。长记录滚动采样仍出现 284 ms 长帧，其中一次布局读取占 203 ms。

## 0.2.4.6 · 2026-11-28

- TUI 按行滚动前唤醒目标位置附近的块，保留末尾四个消息块；渲染中的历史较短时也恢复阅读锚点。历史预取距离随已挂载的内容长度调整。
- 工具计时移除整回合重绘兜底，AGY 的多回合变更分帧处理。输入或滚动时取消排队的窗口截图并推迟后台标签预热。
- 11 px 原生窗口实测，截图所在 AGY 对话 300 帧滚动并输入 30 字，修前／修后最长帧 58／43 ms。旧标签切换版本同操作为 68 ms。当前 Codex 对话 360 帧、36 字，P95 18 ms、最长 32 ms。独立窗口未稳定复现用户截图中的大片空白。
- 额度与 Context 首次展开均从实际输入框的横线定位，11 px 下两者与底线实测均相差 0 px。

## 0.2.4.5 · 2026-11-28

- 本地图片引用读取和解码后挂载悬停框，读取失败时回退到路径。扩展名判断复用文件预览的图片类型表。

## 0.2.4.4 · 2026-11-28

- 本机首屏取消启动动画和非关键等待，按用户与窗口缓存最近画面。三次独立启动恢复到可见工作区的中位数由 579 ms 降至 315 ms。
- Codex 首次从末尾读取 256 KiB，按回合边界补读，历史重建按时间片执行。11 px 字号上滚约 8.3 万像素，帧间隔 P95 为 18 ms，最长 34 ms。
- Web 构建按内容生成静态资源版本。大 JSONL 使用有界字节分页，演示文稿按预览视口缩放。
- Context 与额度共用弹层外观规则，保留单色明细。

## 0.2.4.3 · 2026-11-28

- Context 共用渲染器使用单色总量条和逐项占比条。独立 Studio 实际打开 AGY 长会话，弹层宽 186 px，显示 323.1k / 512k。
- WebKit 压力事件路由到 Quick Look，外链使用内置网页预览。本机文件引用一次测得首帧 48 ms，正文 68 ms。悬停标签按窗口宽高缩放。
- Codex 和 AGY 按设备上的会话 ID 标记归类，隔离运行器在新建会话时传递来源。现有记录保持可读。真实侧栏显示 8 条 Codex、1 条 AGY 验证记录。
- AGY 读取 cascade 状态，ACP 回收前检查后台任务。GUI 与 TUI 增加等待子代理状态。
- 设备报到串行化，30 秒内去重，临时错误退避重试。最近两段七天样本量分别为 29,041、577 次，请求平均耗时分别约为 715、758 ms。

## 0.2.4.2 · 2026-11-28

- 访达刷新目录和筛选结果时复用已挂载的搜索框和祖先节点，支持输入法组合输入。独立 Studio 打开真实空目录后正文留白，输入「目录」后在中间插入「查」，刷新后仍是「目查录」，光标位置为 2。
- TUI 吸顶提示按已挂载块二分定位，历史补绘限制预取距离，输入开始和组合输入期间延后后台补绘。普通运行工具逐项刷新计时。570 回合的 AGY 长会话连续向上滚动仍有间歇性长帧，尚未归零。
- AGY 的空思考增量也建立思考块。终端观测到思考状态切换时通知正文刷新。待译思考按原文行数预留高度，阅读位置上方的思考块翻译后按高度差调整滚动位置。

## 0.2.4.1 · 2026-11-28

- 同组 TUI 标签复用已挂载的正文并调整叠放顺序。恢复布局后在空闲时间准备后台对话；切换时先交接输入焦点，下一帧后补绘变化并保存布局。预览的变换属性不再向正文继承。
- 在独立 macOS Studio 中从当前窗口的四个会话 ID 恢复相同比例的左右分屏。修复前右侧三个真实标签的点击处理最高 235 ms，下一帧回调最高 263 ms。修复后先悬停再点击 24 次，23 次在 2–3 ms 内完成处理和同步布局，第一次为 6 ms；下一帧回调为 8–15 ms。24 次都命中目标面板及其输入框。向上滚动后切走再返回，scrollTop 保持 9265，持久化选中索引为 2。
- 滚轮首事件立即响应，后续事件按帧合并；拖分隔线时复用历史回合的渲染版本，避免相同宽度和内容重复解析 HTML。收藏来源行按名称高度换行。
