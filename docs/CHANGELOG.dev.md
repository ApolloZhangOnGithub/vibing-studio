# Vibing Studio 开发日志

公开版说明见 [changelog.js](../ui/studio/changelog.js)。以下按实际交付版本记录实现与验证。

## 0.2.3.5 · 2026-11-27

- 收藏卡片和详情复用 TUI Markdown 与 ANSI 渲染器，按当前字体格宽及容器可用宽度换行，移除详情宽度上限。新收藏保留原文长度。卡片只处理预览片段，选择卡片时保留列表 DOM。详情按 16 行分块，用可见区域决定何时生成终端字格。
- 分类侧栏可收起并记住状态，折叠按钮使用固定位置。详情工具栏与标题共用一行，窄栏使用带操作名称的图标，移除插入按钮和卡片的来源副行。
- 使用独立 macOS Studio 窗口逐条打开本机已有的 9 条收藏，滚到 Firstlight 收藏末尾，确认末行报告链接显示。详情宽度随边栏从 528 到 698 再回到 528 像素，预览及正文分别为 11 和 12 像素。折叠前后按钮坐标一致，图标与窄栏内容区中心偏差为零。

## 0.2.3.4 · 2026-11-27

- Finder 的应用入口固定打开文件主目录，复用标签时只匹配文件地址。侧栏底部的切换器暂不渲染，保留其实现。
- 在独立 Studio 中选用旧版 Agent 偏好并打开 Agent Finder，然后从应用入口打开访达。普通打开和新标签都进入文件主目录；侧栏显示 Macintosh HD，切换器和底部容器均为零。浏览文件夹后再次打开可复用现有文件标签。

## 0.2.3.3 · 2026-11-27

- 固定会话标签单独绘制完成角标，避免后台状态刷新、悬停预览或程序切换标签清除未读标记。点击固定标签时清除标记，布局序列化保留待确认状态。同一会话在多处打开时共享完成事件，各标签分别确认。
- 实测在独立 Studio 窗口固定一个新 AGY 会话并发送消息。回复完成后右上角出现 5 像素蓝点，颜色为 `#388CFF`。切走、通过工作区切回并等待下一轮刷新，蓝点仍然可见；点击固定标签后，再次刷新仍无蓝点。此次端到端验证覆盖 AGY。

## 0.2.3.2 · 2026-11-27

- **标签图标**　空闲图标的灰色样式此前也匹配选中的标签。在 `ui/studio/studio.css` 中将选中状态纳入配色判断。独立 Studio 窗口打开一个已结束的 AGY 会话，读取 SVG 实际填色，普通标签和 32 像素固定标签均有 16 色，切到后台为单色，再次选中恢复 16 色。此次实际测量覆盖 AGY。
- **发行说明**　按工作会话和验证记录回补 0.2.3.1 的中英文说明，从 6 条增至 17 条。从设置打开更新页后逐条检查，中文界面实际呈现了全部 17 条。
